# Netflix-inspired Web Technologies Project — Assignment 1

A **student-built streaming website mockup** created with plain HTML and CSS. Not affiliated with Netflix.

## Pages
- `index.html` — Home: typography, backgrounds, borders, IDs/classes, links.
- `media.html` — Movies & TV: image, video, audio, ordered and unordered lists, table, box model, position, display, float, overflow.
- `register.html` — Join: HTML5 input types and validation, CSS attribute selectors, pseudo-classes and pseudo-elements.

## Run
Open `index.html` in a browser or use the VS Code Live Server extension. Internet is required for the current external sample images, video and audio. For an offline demo, download licensed assets into `assets/` and update references.
